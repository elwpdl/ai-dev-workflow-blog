# Hello World!

AI Dev Workflow 샘플 블로그에 오신 것을 환영합니다.

이 블로그는 AI 코딩 에이전트와 인간 개발자가 효율적이고 안전하게 협업하기 위한 체계를 실습하고 증명하는 프로젝트입니다.

## 앞으로 다룰 내용
- **W1**: 프로젝트 헌법(`claude.md`)과 도구 후크(Pre/PostToolUse Hook)
- **W2**: MCP 연동 및 GitHub CLI 협업 자동화, E2E 검증
- **W3**: 컨테이너화(Docker), 에러 관측(Sentry), AI 코드 리뷰
- **W4**: PRD 기반 캡스톤 기능 개발 및 완주

작은 단위의 변경과 확실한 테스트, 그리고 명확한 문서화로 신뢰할 수 있는 개발 사이클을 만들어갑니다.
