# GitHub MCP 실제 연결 증거

확인일: 2026-09-20
실제 응답 원본: mcp-live-response.json

실행 대상은 저장소 scripts/github-mcp.sh이며 JSON-RPC stdio로 직접 연결했다.
initialize → notifications/initialized → tools/list → tools/call(get_issue)를 수행했다.
서버: github-mcp-server 0.6.2 / 도구 26개 / elwpdl/ai-dev-workflow-blog 이슈 #1 조회 성공.
클라이언트명은 w2-verification이다. Claude나 다른 제품 UI에서 연결한 기록으로 해석하지 않는다.

설정 경로:
- Claude Code·Copilot CLI: .mcp.json
- Codex: .codex/config.toml
- Antigravity: .agents/mcp_config.json
- 공통 등록 이름: repo-github

현재 셸에 GITHUB_TOKEN과 GITHUB_PERSONAL_ACCESS_TOKEN이 없어 기존 gh 인증을
메모리에서 읽어 자식 프로세스의 GITHUB_TOKEN으로만 전달했다. 토큰은 파일과 로그에
저장하지 않았다. 실제 CLI 사용 시 호스트 프로세스에도 해당 환경 변수를 제공해야 한다.

권한 경계:
- 읽기: search_code, search_issues, get_issue, get_pull_request 등 조회 작업.
- 쓰기: create_issue, create_pull_request, create_pull_request_review 등 원격 상태 변경.
- 사용자 명시적 지시 없이 쓰기·병합·브랜치 갱신을 수행하지 않는다.
- 이번 검증은 get_issue만 호출했고 원격 상태를 변경하지 않았다.
- MCP 등록 자체는 읽기 전용 ACL이나 승인 게이트가 아니다. 제공되는 쓰기 도구도
  tools/list에 포함된다. 토큰 scope와 호스트 권한 정책으로 실제 접근을 제한해야 한다.
- 사람 리뷰·CI 확인은 운영 절차이며 현재 MCP 설정이 이를 기계적으로 강제하지 않는다.
